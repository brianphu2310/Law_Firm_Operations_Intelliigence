# Business analysis pack

How the Principal's questions became the dashboard, written the way a Business Analyst would hand it over.

| Document | What it covers |
|---|---|

| [STAKEHOLDERS.md](STAKEHOLDERS.md) | Who asks, who supplies the data, who decides, and a RACI for each decision |
| [PROCESS.md](PROCESS.md) | The monthly decision cycle, as-is and to-be, and the controls that keep the numbers trustworthy |
| [USER_STORIES_UAT.md](USER_STORIES_UAT.md) | User stories with acceptance criteria, UAT results, and the automated test that proves each one |
